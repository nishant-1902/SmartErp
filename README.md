# SmartERP

SmartERP is a planned full-stack ERP application for managing business operations through a React web interface and a Django REST API backed by MongoDB. The design keeps business rules and authorization on the backend, uses PyMongo for database access, and documents safe handling of stock, money, and authentication.

## Planned tech stack

- Frontend: React (JavaScript) with Vite
- Backend: Django and Django REST Framework
- Database access: PyMongo only; Django ORM is not used for application data
- Database: MongoDB

**Status: Phase 1 in progress**
